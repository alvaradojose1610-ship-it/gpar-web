# GPar Web

Portal comercial público de Distribuidora GPar.

**Sitio:** https://gparsoluciones.com

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS
- Lucide React

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run typecheck
npm run build
```
